法定实缴资本与验资锁资账户流程 强制验资锁定

对于ISIC 6201型外商独资企业而言，无需遵守法定的最低实收资本要求，也无需设立冻结的托管账户。股东可以在公司章程中设定任何合法的注册资本金额，包括10,000元人民币；根据2023年公司法第47条规定，所有认缴的资本必须在企业成立后的五年内完全支付完毕。资本可以以现金或合法实物形式投入，如果投资者为外国人或台湾居民，则必须通过外商独资企业的外汇资本账户进行汇出，且需经过外汇登记手续。

注资与解冻路径: 对于非工业办公场所而言，此规定不适用；一般商业建筑消防安全认证以及房东提供的灭火器合规要求仍然有效，但无需办理民防消防许可、制造相关结构荷载检查或工业设施工作场所安全批准。

实缴资本规则: 对于ISIC 6201型外商独资企业而言，无需遵守法定的最低实收资本要求，也无需设立冻结的托管账户。股东可以在公司章程中设定任何合法的注册资本金额，包括10,000元人民币；根据2023年公司法第47条规定，所有认缴的资本必须在企业成立后的五年内完全支付完毕。资本可以以现金或合法实物形式投入，如果投资者为外国人或台湾居民，则必须通过外商独资企业的外汇资本账户进行汇出，且需经过外汇登记手续。

董事会首期决议范本 (Pro-Forma First Board Resolution)
鉴于公司的唯一股东决定根据中华人民共和国法律将公司设立为外商独资企业，其注册资本应按照公司章程进行认缴和缴纳。且董事们已获得授权，可以采取所有必要的注册和治理措施以开展合法业务；同时，由于该公司从事 ISIC 6201 公共商业网络抓取及代理 API 网关服务业务，股东已召开第一次董事会，以批准公司的组织与运营基础；因此，第一次董事会决定如下：(1) 公司注册与股本认购：董事会采纳所提交的公司章程。确认《公司章程》中规定的公司注册资本总额，并授权法定代表人开立出资账户、发出出资通知，并在股东名册上记录所有股东的出资情况。(2) 注册地址：注册地址应为设立申请中指定的地点，法定代表人有权办理办公场所租赁事宜，并向当地市场监督局和税务机关提交租赁及财产所有权相关文件。(3) 银行账户与银行授权：公司应与管理层选定的银行开立基本存款账户、一般存款账户以及必要的外汇资本账户；董事会指定总经理和财务官员作为授权签署人。所有金额超过20万元人民币或3万美元的支付，需要双方签名；所选银行有权使用经认证的决议副本以及法律代表身份证明。(4) 法定人员任命：董事会根据相关任命书，任命初始法律代表、总经理及监事；总经理拥有日常管理权力，而监事则负责监督董事及高级管理层。(5) 工业许可与合规要求：董事会确认，初始业务范围无需办理实体制造许可证、环境影响评估或民防消防许可；若实际运营涉及受监管的电信服务或互联网内容业务，管理层应立即通知董事会。或数据托管相关活动。(6) 效力：本决议一经通过即生效，构成公司的具有约束力的公司行为。公司秘书须将本决议记录在法定会议记录中，并向银行、税务机关及相关政府登记机构分发经认证的副本。

电子政务申报门户

设立台湾分支机构或子公司之外国非居民实体，须首先向经济部申请业务登记核准。在完成业务登记后之法定期限内，且在开始产生应税销售行为之前，该实体须向其注册业务地址所属之国家税务总局申请税务登记。申请时应提交经核准之章程/备忘录及登记证书、指定之税务及财政代表之身份证明文件，以及分支机构或公司申请人的相关资料。经核准登记后，国家税务总局将核发法定之统一编号（税号），该编号将用于所有营业税、统一发票、申报及缴纳税款之义务。该外国实体须指定一名常驻税务代理人，以处理诉讼文书送达及税务通知事宜。

税号代号与申请路径: Entity_Level_Taxation — 设立台湾分支机构或子公司之外国非居民实体，须首先向经济部申请业务登记核准。在完成业务登记后之法定期限内，且在开始产生应税销售行为之前，该实体须向其注册业务地址所属之国家税务总局申请税务登记。申请时应提交经核准之章程/备忘录及登记证书、指定之税务及财政代表之身份证明文件，以及分支机构或公司申请人的相关资料。经核准登记后，国家税务总局将核发法定之统一编号（税号），该编号将用于所有营业税、统一发票、申报及缴纳税款之义务。该外国实体须指定一名常驻税务代理人，以处理诉讼文书送达及税务通知事宜。

强制登记营业额门槛 (Nexus)

对于标准的商业税收登记，没有统一的营业额限制标准；任何在台湾进行应税商品或服务销售的人必须在开始营业前进行登记。那些每月平均营业额低于8万新台币的商品交易或4万新台币的服务交易的小型经销商，可以适用简化的1%非增值税征收制度，而无需办理标准的增值税申报手续。

跨境出口 0% 零税率申报条件

根据《增值与非增值业务税法》第7条，对于从台湾实际出口的商品以及向外国客户提供的服务，如果这些服务在台湾未被使用且报酬以外币支付，则适用零税率。对于公共商业网页抓取和代理API业务模式而言，只要能证明接收方是非台湾实体、服务在台湾境外进行或使用，且出口收入被汇回台湾即可获得零税率待遇。

  • 台湾海关核准的出口报关单（出口海关申报）
  • 提单或航空运单，证明货物的实际出口
  • 商业发票和装箱单
  • 外汇收入证明书/境内汇款证明书（FIRC）由经授权的国内银行出具

所有注册增值税的商业实体必须就应税销售开具统一发票。符合条件的商业实体须采用电子统一发票，并将发票数据通过“一站式”接口直接传输至财政部电子发票一体化平台，或通过经批准的共同承运商/增值服务中心进行传输。台湾地区不实施实时连续财政核销或数字盖章；反欺诈保护措施包括强制性的统一发票编号序列、电子数据核对、消费者加密码以及平台的验证控制机制。

国家税务局可以对零税率出口商品进行文件及交易审计。如果出口报关单、运输单据或外汇入汇凭证缺失、不实或不足，之前被视为零税率的商业税将被追回，并需支付5%的附加费。根据《增值与非增值商业税法》，因虚假记录导致的少缴税款将面临最高达少缴税款3倍的罚款。伪造报关单或汇款单据还可能依据《税收征收法》及相关的海关相关刑法规定构成犯罪责任。

外汇管制与央行政策诊断

经常项目兑换自由度

人民币可用于处理经常账户项目，包括来自商业数据API业务的跨境服务贸易收入，以及来自实际实现的税后利润的股息支付，但需提供真实的验证文件。资本账户项目则仍需经过SAFE注册：进入的股权资金、跨境贷款（外债）以及出口担保均需要进行注册或备案。利润汇出方面的要求相对宽松：股息支付需满足以下条件：(i)经审计的法定财务报表；(ii)外商独资企业董事会利润分配决议；(iii)SAFE外汇业务注册证书或其在线记录；(iv)企业所得税缴纳证明或付款凭证；(v)当汇款金额达到或超过50,000美元等值门槛时，还需提供必要的税务/备案记录（服务贸易及其他项目外汇支付税务备案记录）。由于外商独资企业采用服务和数据管道出口模式，因此无需进行海关申报，但银行和SAFE会对相关的API使用及收入情况进行更严格的真实交易验证。

出口外汇强制结汇要求

强制性的出口收入上缴制度于2012年被取消。外商独资企业可以将全部出口收入保留在境内外币运营账户中，无需遵循任何法定兑换比例。不过，服务出口的遣返必须进入境内银行账户，且必须在贸易监控验证期内完成（通常商品为180天；服务收入则按合同分别评估）。所得款项可由外商独资企业自行决定在银行兑换为人民币，前提是收据能够追溯到通过合同、发票以及抓取-API和代理服务的相关交付/使用记录所证明的真实服务贸易交易。

央行监管: 中国人民银行（PBOC）；外汇管理职责由国家外汇管理局（SAFE）承担，其省级分支机构负责外商独资企业（WFOE）的登记、监控及执法工作。

跨境清算通道与结算适配

台湾股东通过SWIFT MT103方式，以美元形式注入股权资本至外商独资企业SAFE注册的资本基金外币账户中。该资本属于直接投资性质，适用国际收支用途代码，例如BOP代码621011。在此之前，外商独资企业必须完成以下事项：(i)向商务部或其授权机构提交市场进入申请；(ii)完成SAFE的外商直接投资注册手续并获得外汇业务登记证；(iii)通过银行对申请代码与汇款说明进行核对。资金到账后，仅可用于自身运营目的，如工资支付、租金支付、税费缴纳、带宽及数据中心服务采购以及一般行政费用。禁止将资金用于第三方股权投资、超出许可的集中交易安排下的关联方贷款、财富管理产品以及非自用不动产投资。对于符合资本账户收入支付便利试点条件的外商独资企业，银行允许进行自我验证付款，外商独资企业需保留相关凭证，但所有文件必须在法定保留期内提交给SAFE。向台湾供应商支付的软件许可费、数据中心带宽费用以及代理基础设施相关费用，需通过SWIFT MT103方式进行支付，相关文件包括服务合同、商业发票以及外商独资企业银行付款指令。商业信用证并不适用于数据和API服务，仅适用于根据国际贸易术语协议下的采购订单所购买的杂项商品。超过50,000美元等值金额的服务费用，需记录在《服务贸易及其他项目外汇支付税务申报记录》中；对台湾居民的支付还需缴纳中国境内的预提税，即跨境应税服务对应的增值税加上非居民收入对应的关税，除非根据两岸双重征税安排或相关条约有减征税率的规定。向台湾股东汇出的股息款项，需通过MT103方式支付，并需提供以下文件作为支撑：(i) 董事会利润分配决议；(ii) 经审计的中国大陆年度财务报表；(iii) 已完成的企业所得税缴纳及10%的股息预提税缴纳情况，或按优惠税率缴纳的情况；(iv) 税务申报记录。所有汇出交易必须确保发票中的货币单位、金额和收款人姓名与实际情况完全一致，以避免被认定为“安全法”规定的违规行为而面临处罚。人民币即期外汇远期交易（远期结算与售汇），结算依据真实、合法的经常项目收入和支出来源。境内外汇掉期（人民币与美元之间的外汇掉期）用于临时性流动性匹配资本流入及股息支付时点。人民币/美元的交叉货币互换，针对匹配的跨境贷款或负债敞口，须经国家外汇管理局登记并完成真实需求核实。采用零成本套头结构，将购买的美元看涨/人民币看跌期权以及美元看跌/人民币看涨期权与获得许可的SAFE指定银行相结合，且对冲风险不得超过经认证的真实交易流量。对于中外合资经营企业（WFOE），境内不允许进行非交割远期（NDFs）交易；境外人民币跨境NDFs被限制为投机性、非实际需求的金融工具，不得用于企业集团的财务管理。

转让定价与经济实质

主文档/本地文档门槛: 本地文件：年度关联交易超过新台币2000万美元；主文件：跨国集团合并收入超过新台币300亿（亦为国别报告的门槛）。

经济实质审查范围: 台湾没有类似离岸中心那样的独立经济实体法规体系，但《税务评估法》第12-1条规定了实质性的税收原则。在台湾没有实际研发活动、运营人员、管理机构、银行账户、董事会决策记录或实际业务活动的外商独资企业，可以被重新定义为空壳企业；其收入可以重新归属于离岸母公司，而台湾的税务申报则被忽略不计。

致命合规红线与董事个人责任

逃税 / 虚假纳税申报

法定制裁: 根据《所得税法》第110条，行政罚款金额不得低于未缴税款的10%，最高可达未缴税款的三倍；根据《税收征管法》第41条，对逃税行为将追究刑事责任，处三年以下有期徒刑，并处或单处罚金。

董事个人责任: 签署或指示虚假申报的董事，应就未缴税款及罚款承担连带和按份责任；国家税务总局可实施出境限制和财产冻结；相关企业负责人将承担刑事责任，可能被判处有期徒刑。
空壳公司 / 缺乏经济实质

法定制裁: 禁止内部交易抵扣、向上调整转让定价、重新定性及重新评估，适用于第12-1条；对故意避税行为处以未缴税款三倍及利息的罚款。

董事个人责任: 董事及受益所有人可在穿透公司外壳后被认定为实际纳税人；对未缴税款超过法定限额的负责人，适用旅行限制令及出境限制。
反洗钱 / 无许可的支付服务提供商运营

法定制裁: 撤销登记、根据反洗钱法处以的行政罚款、虚拟资产没收、由主管部门责令暂停营业或关闭。

董事个人责任: 合规官和董事若明知协助洗钱，将面临最高七年监禁及罚款；在调查期间，还可能被实施旅行禁令和资产冻结。
扣留和遣返违规

法定制裁: 税务机关直接从预扣代理人处收取未预扣金额；对于故意不预扣的情况，将按未预扣金额的1.5至2倍征收附加费，同时还会从原支付日期起计算惩罚性利息。

董事个人责任: 明知批准未扣缴的跨境汇款的董事，须就额外税款及罚款承担个人责任；负责财务的高级管理人员若未缴清企业扣缴税款，可能面临刑事起诉及旅行禁令。
